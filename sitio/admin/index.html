Administración de encuestas

Conectar con GitHub

Este panel guarda y modifica encuestas escribiendo directamente en el repositorio Pol4720/IATools, usando la API de GitHub. Para eso necesita un token personal de acceso (PAT) de su propia cuenta de GitHub, con permiso de escritura solo sobre este repositorio.

  1. Vaya a github.com/settings/personal-access-tokens/new (token de tipo fine-grained).
  2. En «Repository access», elija «Only select repositories» y seleccione Pol4720/IATools.
  3. En «Permissions → Repository permissions», dé a Contents el acceso Read and write.
  4. Genere el token y péguelo aquí abajo. Se guarda únicamente en este navegador (nunca se envía a ningún sitio salvo api.github.com).
